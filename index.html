How it works

1. Save

Type text, choose a code and tap Save.

2. Share the code

Send the code, link or QR to your other device.

3. Pull

Enter the code there, tap Pull, then Copy.

Privacy

No account and no tracking. Saved text is stored in a cloud database under your code, and anyone who knows the code can read or overwrite it. Use a long random code and don't store secrets.
